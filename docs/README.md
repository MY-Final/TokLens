# TokLens 规范文档

`AGENTS.md` 是入口规范，这里存放需要展开说明的三份子规范：

| 文档                                     | 内容                                               | 何时更新                                       |
| ---------------------------------------- | -------------------------------------------------- | ---------------------------------------------- |
| [`architecture.md`](./architecture.md)   | 分层与依赖方向、前后端契约、客户端适配器、架构决策 | 新增目录、模块边界、依赖、持久化方案、测试框架 |
| [`ui-guidelines.md`](./ui-guidelines.md) | 视觉语言、布局、组件、数据可视化、无障碍           | 新增设计约定、组件规范、可视化规则             |
| [`data-metrics.md`](./data-metrics.md)   | 数据来源分级、归一化模型、统计口径、估算规则、隐私 | 新增指标、修改口径、调整价格表或估算公式       |

维护约定：

- 命令以 `package.json` 为准，本文档不重复维护命令清单。
- 四份文件（含 `AGENTS.md`）必须保持一致：术语（`measured` / `derived` / `estimated`）、目录路径、命令名称。
- 规范变更与代码变更放在同一个提交里，并在提交说明中说明原因。
