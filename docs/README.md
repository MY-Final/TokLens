# TokLens 规范文档

`AGENTS.md` 是入口规范，这里存放需要展开说明的子规范与调研记录：

| 文档                                                   | 内容                                                                                                  | 何时更新                                       |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| [`architecture.md`](./architecture.md)                 | 分层与依赖方向、前后端契约、客户端适配器、架构决策                                                    | 新增目录、模块边界、依赖、持久化方案、测试框架 |
| [`ui-guidelines.md`](./ui-guidelines.md)               | 视觉语言、布局、组件、数据可视化、无障碍                                                              | 新增设计约定、组件规范、可视化规则             |
| [`data-metrics.md`](./data-metrics.md)                 | 数据来源分级、归一化模型、统计口径、估算规则、隐私                                                    | 新增指标、修改口径、调整价格表或估算公式       |
| [`data-model.md`](./data-model.md)                     | 统一数据模型、Token 语义、去重键、SQLite 表结构                                                       | 修改模块映射、表结构、去重键、口径或迁移时     |
| [`data-source-research.md`](./data-source-research.md) | Codex / Claude Code / OpenCode / DSH / Kimi Code / MiMoCode / Pi Desktop 本机数据来源、字段映射与限制 | 数据源结构、字段或客户端版本行为变化时         |

维护约定：

- 命令以 `package.json` 为准，本文档不重复维护命令清单。
- `AGENTS.md` 与 docs/ 下的所有文档必须保持一致：术语（`measured` / `derived` / `estimated`）、目录路径、命令名称。
- 规范变更与代码变更放在同一个提交里，并在提交说明中说明原因。

代码定位与模块依赖图统一维护在 `architecture.md`，数据模型实现位置维护在 `data-model.md`。
结构重构时同步更新这些索引；提交描述统一英文，测试按行为组织，详见 `AGENTS.md`。
