# UI/UX 设计规范

## 桌面设置约定（2026-10-11）

设置入口位于侧边栏底部；页面按通用 / 外观与统计 / 采集 / 更新 / 数据与隐私 / 关于分类，
设置页采用固定的第二级分类侧栏与右侧内容面板；800px 及以上窗口始终保留分类侧栏，宽度 176px，宽窗口为 208px。
分类带图标，按应用 / 管理分组，使用背景与文字颜色标记选中态；内容以标题、说明与分隔线组织设置行，控件在空间不足时换行。
使用现有 Button、Switch、Select 与 Dialog，不显示统计日期筛选器。
设置即时保存且失败保持实际值；首次进入通用，托盘更新入口直接进入更新分类。新安装、缺失设置与恢复默认使用今天，保留已有用户的统计范围选择。
首次关闭询问退出或缩小到托盘，可记住选择、可取消；删除统计及恢复默认设置必须确认。
主题支持系统 / 浅色 / 深色；版本从原生运行时读取。更新默认手动，下载与安装分别由用户触发。
关于页面提供沟通群聊入口，显示可选中的 QQ 群号 `668526188`，用于反馈问题与交流建议。
开启自动检查后每天最多检查一次，仅发现新版时提示版本和最多两条说明摘要；Sonner 气泡可关闭，12 秒自动收起，后台发现同一版本每次运行只提示一次。手动检查每次均反馈结果，进行中立即禁用操作并显示阶段。
侧栏常驻“检查更新”，点击一次打开更新弹窗并检查；已有新版或正在下载时入口显示当前阶段，点击只查看已有状态。气泡“查看更新”同样直接打开更新弹窗；弹窗与设置复用同一更新面板，直接展示版本、纯文本发布说明和当前阶段的主操作，无需跳转。下载与安装分别点击，安装按钮旁注明关闭应用及保留统计，不再叠加确认弹窗。不加载发布说明中的远程图片或 HTML。
下载进度使用 MB 与百分比；未知总大小仅显示已下载量。可关闭弹窗继续下载并从侧栏返回；已下载时只提供安装操作，托盘检查不丢弃已验证更新包。检查失败提供重试，下载失败提供重新下载。
隐藏窗口继续本地采集；清除统计后明确显示已暂停及恢复入口，不以自动重导入掩盖清除结果。

Windows 托盘右键菜单提供采集状态、上次采集、暂停 / 恢复、立即采集、采集频率与页面快捷入口。
采集中或暂停时禁用立即采集；采集中暂停说明当前采集完成后停止后续采集，设置页与托盘反映同一实际设置。
频率子菜单选中当前值（关闭 / 1 / 5 / 15 / 30 分钟）；关闭定时采集与暂停采集为不同设置，关闭定时仍可手动采集。
悬停摘要注明“今日、本地、按请求时间”，只展示已记录请求和已知 Token；无记录、全部未知和部分未知分别说明，不把未知显示为实测零。
托盘只显示聚合数据，不包含项目路径、会话标识或正文；摘要加载失败显示暂不可用，不能保留一个看似最新的旧数字。
检查更新打开设置的更新区域，展示检查状态及结果；点击触发固定发布源检查，不自动下载或安装。

TokLens 是长时间驻留的桌面工具型应用：界面应安静、克制、信息密度优先，让数据本身成为视觉焦点。
风格基调：**简洁、现代、以白色与中性色为主**，参考 Linear / Raycast 的克制工具界面。

## 1. 设计原则

1. **内容优先**：先结构（标题、筛选、数据）再装饰；任何视觉效果都不能影响读数的准确性。
2. **克制**：一个页面只保留一个视觉重点；使用统一面板，避免多余的装饰、阴影和动效。
3. **一致**：颜色、间距、圆角、图表配色来自统一 token；同类信息在全局使用同一种呈现方式。
4. **可信**：实测与估算数据在视觉上必须可区分，单位与时间范围必须可见（见第 6 节与 `data-metrics.md`）。
5. **桌面优先**：窗口默认 1000×700，最小 800×600；不为移动端做适配，但小窗口下主内容不得溢出或错位。

### 界面文案（2026-10-12）

- 标题、控件与数值能表达的信息，不重复写成副标题、段落或页脚；设置分类无需常驻介绍。
- 常驻说明只保留范围、单位、统计模式及条件性异常。详细公式、目录配置与归一化规则集中到键盘可访问的“数据说明”。
- 未知、已知子集、不完整与估算标记直接可见；空状态用一句短操作提示。清除、恢复默认与联网检查保留必要后果提示。
- 隐私说明集中在数据与隐私分类及来源页，不在各页面重复；尚未展示的费用无需占用界面解释。

### 数据源诊断（2026-10-13）

来源卡片显示实际扫描根路径及可访问 / 不存在 / 无法读取状态，根路径可访问不宣称全部文件可读。最近检查注明仅本次运行；最近导入与最近用量记录分开，无原生时间保持 `—`，Grok 保留轮结束时间说明。读取失败、部分解析与 Token 总量未知直接可见，真实零不显示为未知。
每个启用客户端提供单独重扫，采集中、暂停或停用时禁用；复用全局同步状态与完成后刷新。脱敏摘要可展开预览再复制，含应用版本、状态、时间与计数，不包含路径、项目 / 会话标识或错误原文；只有用户点击复制才写入剪贴板。

## 2. 颜色与主题

- 只使用 `src/index.css` 中定义的语义 token（通过 Tailwind 类使用）：
  `background` / `foreground` / `card` / `popover` / `primary` / `secondary` / `muted` / `accent` / `destructive` /
  `border` / `input` / `ring` / `sidebar*` / `chart-1..5` / `client-codex` / `client-claude` / `client-opencode`。
- **禁止**在组件里写死颜色（`bg-white`、`text-neutral-500`、`#fff`、`rgb(...)`、内联 `style` 色值）；
  例外只有 `src/index.css` 的 token 定义本身。
- 客户端标识稳定使用品牌 token：Codex 绿色，Claude Code 暖橘色，OpenCode 蓝紫色；颜色值只在 `src/index.css` 定义。
- 暗色模式通过 `.dark` 覆盖 token 实现，组件内不得写"暗色分支"逻辑。
- 强调色用于主操作与选中态，保持稀缺；大面积区域使用 `background` / `muted` 这类中性底色。

## 3. 层次、间距、圆角、字体

| 维度 | 规则                                                                                                                   |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 层次 | 优先用 1px 边框（`border`）+ 背景色差 + 间距分层；浮层使用阴影，统计面板可使用极浅阴影与 `bg-card/50 backdrop-blur-sm` |
| 间距 | 使用 Tailwind 4px 网格（`gap-2/3/4/6`），同一列表项内间距一致，不要出现 `13px` 之类的散值                              |
| 圆角 | 由 `--radius` 派生：容器 `rounded-xl`、控件 `rounded-md`、标签/徽标 `rounded-sm` 或全圆                                |
| 字号 | 正文 `text-sm`；标题 `text-base`/`text-lg`；辅助信息 `text-xs` + `muted-foreground`；不要使用 `text-2xl` 以上做装饰    |
| 数字 | 表格与指标使用 `tabular-nums`；ID、模型名、路径等用等宽字体                                                            |
| 动效 | 仅用于状态反馈，时长 ≤ 200ms；不使用装饰性动画                                                                         |

## 4. 布局

- 主工具栏整合页面标题、时间范围、同步状态、刷新与更多操作；不重复展示页面副标题和工作空间标签。
- 重新扫描位于更多菜单，上次同步、扫描计数和错误详情位于同步状态浮层；暂停与同步异常直接可见。
- 同步期间主工具栏与数据源页显示进度条、当前客户端及已处理 / 启用的数据源总数；进度按处理数量推进，不代表剩余时间，缺失与失败来源同样算已处理。状态未返回时显示准备状态，不伪造百分比；同步结束收起进度条并展示成功或异常结果，不阻塞已有数据浏览。
- 导航固定展开为 208px，始终显示图标与文字；不提供折叠按钮或 Ctrl+B 切换。底部保留已有更新与设置入口。
- 主框架：左侧导航（`sidebar`）+ 右侧内容区；导航项保持在 7 个以内，超出请重新分组。
- 统计页面的常用时间范围（今天 / 7 天 / 本周 / 30 天 / 本月 / 90 天 / 全部）直接放在主工具栏，与标题和同步操作共用一行，点击一次即时切换；自定义使用有无障碍名称的日历按钮，通过浮层编辑与确认。精确区间和本地时区作为按钮下方的辅助文字，不占用独立内容行；窄窗口允许按钮在工具栏内换行，区间过长截断并可悬停读取完整值。设置与数据源管理不显示日期筛选。
- 页面结构：标题与时间范围等工具栏 + 主内容（表格、图表、明细），主内容优先铺满可用宽度。
- 总览使用四个核心指标卡片、趋势、分布与排行面板；统一 `DashboardCard` 外观，**禁止卡片嵌套卡片**。
- 列表与表格是主要呈现方式，避免用大量小卡片堆叠替代表格。
- 三态必须实现：加载用 `skeleton`，空数据用空状态文案（说明"没有数据"与"如何产生数据"），
  错误用内联提示（`text-destructive`）+ 可重试操作，不要用原生 `alert`。
- 定时采集和滚动日期范围更新时保留上一份已成功数据，后台请求完成后原位替换；不要因后台刷新让整页闪成骨架或跳回顶部。

## 5. 组件使用

- 优先使用已存在的 shadcn/ui 组件（`button`、`input`、`select`、`table`、`tabs`、`dialog`、`alert-dialog`、
  `dropdown-menu`、`popover`、`tooltip`、`badge`、`progress`、`scroll-area`、`separator`、`skeleton`、`switch`、
  `calendar`、`card`、`command`、`sheet`、`sidebar`、`sonner`）与 `lucide-react` 通用图标；AI 客户端品牌图标使用用户指定的 `@lobehub/icons`。
- **不要引入新的业务 UI 组件库或未经登记的图标库**（antd、MUI、Chakra、Element、其他图标集等）。
  `@lobehub/icons` 是已登记的 AI 品牌图标例外，其 peer 依赖不用于业务组件。缺少组件时按 shadcn 方式补充：
  `pnpm dlx shadcn@latest add <component>`，并把生成文件视为 vendor 代码（不手改、不加入 `eslint.config.js` 的强规则范围）。
- `src/components/ui/**` 与 `src/hooks/use-mobile.ts` 是生成物：需要调整外观时优先在业务组件里组合 Tailwind 类，
  而不是修改生成文件；确需修改时必须在提交说明中写明原因。
- 图标默认 `size-4`（16px），图标按钮必须有 `aria-label` 或 `tooltip`，禁止用 emoji 代替图标。
- 所有可交互元素必须提供 `hover` / `focus-visible` / `disabled` 状态，键盘可达（Tab 顺序符合阅读顺序）。
- 筛选下拉统一使用 `FilterSelectContent`：浮层从触发框下方展开、左边缘对齐、与触发框等宽，保留 4px 间隙。
  不使用按选中项对齐的覆盖式定位；空间不足时由 Radix 自动避让窗口边缘，保留键盘选择与滚动能力。
- 通知统一使用 `sonner`，不要在页面内自建 toast。

## 6. 数据可视化（recharts）

- 图表必须包含：指标名称、单位、时间范围；无数据时显示空状态而不是空坐标轴。
- 颜色只能使用 `--chart-1` ~ `--chart-5`；同一指标在所有图表中使用同一颜色，客户端/模型维度配色保持稳定。
- **估算数据处理**（与 `data-metrics.md` 的 `estimated` 等级一致，必须可区分）：
  - 估算系列使用虚线或更浅的填充，并在图例、tooltip、坐标轴标注"估算"；
  - 估算值不得与实测值直接相加后作为一个数展示；需要合并展示时必须同时给出拆分；
  - 无法估算时显示 `—`，不要显示 0。
- tooltip 必须给出该数值的口径（例如"实测 token / 含缓存"）与单位；金额标注币种。
- 趋势 tooltip 按当前指标值降序展示客户端分项（未知排最后，同值保持稳定顺序），请求时间与会话累计模式均显示用量；Token 构成浮框同样按值降序。
- 趋势与热力图 tooltip 用日期、突出的当日已知 Token、计数及条件性异常提示分行呈现，直接使用后端总量。请求时间和会话累计的归属标签必须区分。
- 单日趋势缩短高度，保留唯一点和日期；首尾日期被精确范围裁剪时标注“所选时段”。未知、部分未知和明细不完整不因说明精简而隐藏。
- 长篇口径与全历史采集覆盖移入可点击、键盘可访问的数据说明浮层，首屏保留范围、单位、模式与短口径；不得把全历史覆盖计数描述成当前范围完整率。
- 趋势浮框通过 Recharts portal 挂到文档根层，由业务组件按图表坐标换算窗口位置并避让四边；不得受卡片毛玻璃、滚动容器或后续卡片遮挡。浮框位于普通内容之上、模态弹窗之下。热力图浮框使用 popover 配色，明暗主题中的文字和背景保持一致。
- 浮框验收（2026-10-12）：合成八客户端在 800 / 1000 / 1440px、600px 高度、单日 / 多日与两个趋势模式中共 24 组均无遮挡、无越界；另 8 组完整数字 / 自动单位与明暗主题通过。键盘触发、Escape 收起与热力图深色配色正常，桌面开发版单日会话累计浮框完整显示。
- 不使用 3D 或装饰性动画；面积图允许透明度不超过 0.2 的渐变填充，不引入第二套图表库。
- 图表要有标题/说明文字，避免只靠颜色传达含义（色弱可读）。

## 7. 文案与数字格式

### 首版热力图（2026-10-11）

日历热力图可切换总 Token / 会话数 / 请求明细，默认最近 365 天，也可选择跟随页面日期；
客户端 × 日期热力图组件展示总 Token，沿用调用页面的日期和客户端筛选；2026-10-12 收束后，用量分析页不再展示该矩阵。
明确显示本地时区与当前统计模式；保留的会话累计模式按会话开始日归属，说明请求数不是该日实际请求数，固定 24 小时桶仍有夏令时偏差。默认请求时间模式按本地日历边界展示实际有时间的非估算请求。
同一面板的所有客户端与日期使用同一强度色阶和全体可见值的共同标尺，不为每行独立归一化；颜色来自语义 token。
图例注明少到多与单位，tooltip 提供单位格式化数值、精确总量、日期、客户端（适用时）及统计口径。
无会话日期显示零活动；有会话且全部总量未知显示 `—`，不使用零值色阶冒充实测零。
混合数据标明“已知子集”及未知会话数；明细不完整单独标注，不隐藏仍已知的 Token 总量。
加载使用骨架，空数据解释如何产生数据，错误提供内联提示与重试；不得以模拟格子代替真实数据。
格子信息必须可通过键盘聚焦与读屏读取，包含精确值和未知 / 不完整说明，不能仅靠颜色传达状态。
复用已有组件与 CSS，不新增图表库、依赖或网络资源。

- 界面文案使用中文；术语与 `data-metrics.md` 保持一致（会话、请求、实测、估算、缓存 token 等）。
- 计数使用千分位；Token 默认自动缩写为 k / M / B，设置支持万 / 亿、固定 k / M / B 与完整数字。统计指标、趋势坐标轴、浮框、热力图图例及列表统一遵循设置；浮框保留精确总量，分项与列表可悬停查看精确值。固定单位下非零小值显示 `<0.01`，不舍入成实测零。
- 时间范围必须显式标注（如"最近 7 天"），并按本地时区聚合；跨时区场景需注明时区。
- 金额统一标注币种（当前为 USD），小于 0.01 美元显示 `<$0.01`。
- 空状态、错误文案要说明"发生了什么 + 下一步怎么做"，避免"出错了"这类无信息提示。

## 8. 无障碍

- 正文对比度 ≥ 4.5:1，辅助文字不低于 3:1；不要用纯色深浅差极小的文字。
- 表格使用语义化表头（`table` 组件），排序/筛选状态可被读屏识别。
- 不使用"仅颜色"传达状态：错误/估算/异常同时提供文字或图标。

## 9. 反模式（禁止）

- 强烈玻璃拟态、霓虹渐变、大面积彩色背景、随机阴影、装饰性发光。
- 卡片套卡片、无关联指标过度拆分、卡片内表格再套边框。
- 硬编码颜色/间距魔数、复制粘贴的"近似样式"。
- 引入未经登记的 UI / 图标库，或第二套图表库。
- 用动画掩盖加载延迟，或用占位内容造成布局跳动。
- 未标注的估算数据、未标注单位的图表、把估算与实测混算成一个数字。

## 10. 提交前检查

- [ ] 颜色全部来自语义 token，无硬编码色值
- [ ] 间距/圆角/字号取自统一尺度，未出现散值
- [ ] 加载、空、错误三态齐备
- [ ] 图表有单位、时间范围与图例，估算系列已标注
- [ ] 图标按钮有 `aria-label`/tooltip，键盘可达
- [ ] 未引入未经登记的 UI/图表/图标库，未修改 `src/components/ui/` 生成代码

## 11. 统计界面约定（TokLens 桌面端）

- **打开即看数据**：不做欢迎页、营销文案或账户中心；首屏直接是统计结果，侧边导航固定为总览 / 用量分析 /
  会话明细 / 数据源管理四项。
- **三态齐备**：每个数据区块都要有加载（骨架）、空数据（说明为什么没有数据、如何产生数据）、错误（可重试）三种状态；
  同步进行中要有明确的进行中状态，且不阻塞已有数据的展示。
- **区分真实 / 未知 / 不完整**：缺失值显示 “—”（不是 0，也不参与合计）；不完整数据（明细被分页/续接）与口径未知项
  （如 Codex 的缓存写入与输入关系）必须在界面上标注，可用 badge 或 tooltip 说明。
- **口径可见**：每个统计卡片或图表旁要有口径说明（tooltip 或脚注），措辞与 `docs/data-model.md` 一致。
- **图表规范**：只用 `--chart-1..5` 语义 token 上色，同类指标在全局使用同一颜色；不用 3D 或装饰动画；允许低透明度面积渐变；
  坐标轴与 tooltip 必须带单位，数值用千分位或 k/M 缩写。
- **不展示费用金额**：在没有可靠成本来源前，界面不出现任何金额或“预计花费”。
- **未接入的客户端**：在数据源管理显示“等待采集”并置灰、虚线边框，不显示 0 或模拟用量；统计区仅保留当前范围有记录的客户端。
